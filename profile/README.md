# Marketing Pull Request

**Antes de virar regra, Marketing passa por revisão.**

Marketing Pull Request é uma forma pública e estruturada de submeter afirmações, modelos, métodos e decisões de Marketing à revisão antes de tratá-los como conhecimento válido, boa prática ou recomendação replicável.

## Como funciona

**Claim** → **Pull Request** → **Review** → **Evidence** → **Discussion** → **Merge / Changes Requested**

O objetivo não é eliminar discordância. É tornar explícito **o que está sendo afirmado, sobre qual objeto, com qual força e com qual sustentação**.

## Um exemplo

> **“O funil morreu.”**

O primeiro review pode começar com uma pergunta simples:

**Qual funil?**

Marketing? Vendas? Jornada do consumidor? Pipeline comercial?

Antes de discutir se uma afirmação é verdadeira, precisamos saber **exatamente o que ela afirma sobre exatamente o quê**.

## O que significa merge

**Merge não significa verdade definitiva.**

Significa que a proposta satisfez os critérios de integridade correspondentes à natureza do claim e ao gênero em que foi apresentada.

Uma proposição mergeada pode continuar sendo criticada, receber nova evidência, ser revisada ou até sofrer **revert**.

## O que revisamos

Claims. Modelos. Métodos. Decisões. Evidências. Definições.

**Não pessoas.**

Audiência, cargo, reputação e autoridade do autor são contexto. Não substituem evidência.

Humor, ironia, sátira, metáfora e hipérbole também são linguagem legítima. O review deve interpretar o gênero antes de avaliar a força do claim.

**A licença retórica protege a forma. Não transforma um fato falso em verdadeiro.**
